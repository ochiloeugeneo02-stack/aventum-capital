## 🧠 BACKEND LOGIC

### Core Rules
- Each group has 5 members
- Each member contributes a fixed amount per cycle
- When ALL members have paid → payout is triggered
- Payout goes to the next user in rotation
- Rotation continues until all members receive payout

---

### Contribution Flow
- User clicks “Pay Contribution”
- Simulate successful payment
- Save to database
- Update group progress

---

### Payout Flow
- When all contributions are paid:
  - create payout record
  - assign to correct user
  - mark as “pending”
- Admin or system can mark as “paid”
- Move rotation index forward
